## Установка

Установите пакет через менеджер пакетов **npm**:

```sh
npm install webview-ui-kit
```

#### Стили

Для работы библиотеки требуется импорт базовых стилей:

```tsx
import 'webview-ui-kit/fonts.css';
import 'webview-ui-kit/styles';
```
