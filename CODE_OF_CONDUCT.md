# Code of Conduct

## 1. Цель
Опишите, зачем вам CoC и какие ценности вы поддерживаете.

## 2. Наши стандарты
- Конструктивная обратная связь
- Приветливость к новичкам
- Запрет: троллинг, оскорбления, дискриминация

## 3. Область действия
Применяется к обсуждениям в GitHub Issues, Pull Requests, чате и встречам.

## 4. Обязанности
- Участники: уважать других, соблюдать эти правила.
- Модераторы: следить за исполнением и реагировать.

## 5. Процесс доклада
1. Напишите на `conduct@ваша-компания.uz` или создайте Issue с меткой `report`.
2. Разрешения: ответим в течение 72 часов.
3. Возможные меры: предупреждение, удаление контента, блокировка.

## 6. Контакты
Контактное лицо: [Name], `conduct@ваша-компания.uz`.

## 7. Юридическая оговорка
Этот документ не является юридическим контрактом.

## 8. Атрибуция
Этот CoC основан на [Contributor Covenant](https://www.contributor-covenant.org/), версия 2.1.
